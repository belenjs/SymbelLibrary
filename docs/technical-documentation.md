# Documentación ténica de SymbelLibrary

## 1. Introducción
### 1.1 Descripción del proyecto
SymbelLibrary es una aplicación web de biblioteca personal, diseñada principalmente para uso en escritorio, cuyo objetivo es gestionar y mantener un registro de las lecturas realizadas. Permite almacenar información de cada libro, registrar las diferentes lecturas realizadas de los mismos y valorarlas mendiante una puntuación personal.

Además, permite gestionar una lista de libros pendientes de leer y consultar estadísticas para llevar un seguimiento de hábitos de lectura, facilitando la comparación de la evolución a lo largo de los años.

### 1.2 Objetivos
El objetivo principal es desarrollar una biblioteca personal para organizar y gestionar las lecturas de una manera sencilla.

Como objetivos específicos se observan:
- Registrar y organizar los libros leídos y pendientes.
- Realizar un seguimiento de las lecyuras y valorarlas personalmente.
- Obtener estadísitcas que permitan analizar hábitos de lectura y la evolución de los mismos.
- Aplicar de forma práctica los conocimientos adquiridos durante el primer curso del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).
- Ampliar conococimientos mediante el uso de nuevas herramientas y tecnologías.

### 1.3 Alcance
La primera versión permitirá gestionar una biblioteca personal directamente desde la aplicación web, evitando que se tengan que introducir los libros desde la base de datos.

El alcance inicial incluye:
- Añadir nuevos libros a la biblioteca desde la interfaz.
- Eliminar libros existentes.
- Consultar los datos de cada libro.
- Registrar y consultar libros pendientes de lectura.
- Registrar lecturas realizadas y su correspondiente valoración.
- Consultar estadísticas.

Queda fuera del alcance inicial:
- Posibilidad de incluir login.
- Buscar libros por ISBN o mediante API externa.
